# 🌍 Triptown

Triptown is a smart travel planning web app that categorizes tourist destinations based on **seasons** and **themes**—helping users find the perfect places to visit depending on the time of year and the type of experience they seek.

## 🚀 Features

- 🗓️ **Season-Based Filtering**: Discover destinations best suited for summer, winter, monsoon, or spring.
- 🎯 **Theme-Based Suggestions**: Browse places by interests like adventure, heritage, relaxation, wildlife, and more.
- 📍 **Dynamic Destination Cards**: Interactive cards with brief details, images, and quick links.
- 🔍 **Search & Explore**: Easily search places based on keywords or filters.
- 📱 **Responsive Design**: Smooth experience across all screen sizes.

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Hosting**: GitHub Pages / Netlify / Vercel
